## File Structure

```
portfolio/
├── index.html       # Main HTML file
├── style.css        # Stylesheet with all styling
├── script.js        # JavaScript for interactivity
├── images/          # Project images (copy from original)

```

## Installation

1. Copy all files to your web hosting server
2. Copy the `images` folder from your original portfolio
3. Update social links in the HTML if needed
4. Deploy and enjoy!

## Customization

### Colors
Edit the `:root` variables in `style.css`:
```css
:root {
    --primary: #000000;      /* Main color */
    --secondary: #1a1a1a;    /* Secondary color */
    --text: #333333;         /* Text color */
    --light-text: #666666;   /* Light text */
}
```

### Content
Edit the HTML in `index.html` to update:
- Personal information
- Project details
- Experience timeline
- Skills list
- Contact information
